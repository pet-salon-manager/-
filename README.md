# PawPal v20.3 — Supabase店舗編集

## 追加
- Supabase店舗マスタの店舗をPawPal一覧へ統合
- 運営管理からSupabase店舗を直接編集
- 編集項目:
  - 店名
  - 種類
  - 都道府県
  - 住所
  - 電話番号
  - ホームページ
  - 営業時間
  - 説明
  - 予約URL
  - クーポン・特典
  - PawPalおすすめ
  - 公開 / 非公開
- Supabase店舗の削除
- 保存・削除はSupabase Authログイン＋RLSで管理者だけ許可
- 同期後、編集内容を即時再表示
- WebサイトURLを店舗詳細のWebボタンへ正しく反映

## 使い方
1. PawPalお店画面で運営管理者ログイン
2. 「⚙️ PawPal運営管理」を開く
3. 「取得済み店舗の情報を編集」で店舗を検索
4. 「編集」
5. 内容を変更して「☁️ Supabaseへ保存」
6. 非公開にした店舗は一般の店舗同期一覧から除外されます

## セキュリティ
Supabase側のRLSが最終的な書き込み制御を行います。
Service Role Keyはアプリへ入れないでください。
