# PawPal v21.4 — 無料API 自動補完キュー

Google Placesなどの課金APIは使用しません。

## 無料ソース
- OpenStreetMap
- Overpass
- Nominatim
- Wikidata
- Wikipedia

## 新機能
運営管理に「🤖 無料API 自動補完キュー」を追加しました。

対象を選べます:
- 住所・電話・HPの未入力
- 住所なし
- 電話なし
- HPなし

1回に調べる件数:
- 5件
- 10件
- 20件

## 安全な動作
- 1店舗ずつ処理
- 無料APIへ連続アクセスしないよう待ち時間を入れる
- 見つかった候補は端末に確認待ちとして保存
- Supabaseへは自動保存しない
- 「候補を確認」から店舗編集を開き、出典を確認して反映

## 推奨
最初は5件で試してください。
動作が安定していれば10件、20件へ増やします。
