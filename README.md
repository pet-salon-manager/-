# PawPal v18.4

## 全国のお店検索

OpenStreetMap / Overpass API を使って、実際に地図へ登録されている以下の施設を検索できます。

- 動物病院
- ペットトリミング
- ペットホテル / 動物預かり
- 現在地周辺検索
- 都道府県 / 市区町村検索
- 現在地から近い順
- 店名・地域・種類で絞り込み
- 電話
- OpenStreetMapで地図を開く
- Webサイト
- お気に入り
- 行ったことがある
- 自分用メモ

### 注意
OpenStreetMapに登録されていない店舗は表示されません。
店舗情報はOpenStreetMapの登録内容に依存するため、営業時間・電話・Webサイトが未登録の場合があります。
検索にはインターネット接続が必要です。
