# PawPal v19.0

## お店情報を大幅強化
- 現在地から50km以内を検索
- OpenStreetMap / Overpass から店舗取得
- Wikidataで公式HP・電話・住所を補完
- Nominatimで不足住所を補完（近い店舗から最大8件）
- PawPal独自店舗を運営管理画面から登録・編集・削除
- 重複店舗を店名・位置・電話番号で統合
- 病院 / トリミング / ホテルに加えてペットショップも検索
- 現在地から近い順に表示
- おすすめ店舗設定を継承
- 住所・電話・ホームページ・営業時間・距離を詳細表示

### 注意
外部データベース側に情報がない店舗は、住所やHPが未登録のままの場合があります。
PawPal独自登録で補完できます。
