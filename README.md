# PawPal v19.1

## 情報源をさらに追加
- OpenStreetMap
- Overpass
- Nominatim
- Wikidata
- Wikipedia（近隣ページから説明情報を補完）
- PawPal独自登録
- PawPal運営側の上書き情報

## 運営管理を強化
- 外部から取得した店舗も編集可能
- 店名
- 種類
- 住所
- 電話
- ホームページ
- 営業時間
- 説明
- おすすめON/OFF

編集内容は外部サービスへ書き戻さず、PawPal側の「上書き情報」として保存します。
次回検索でもPawPal側の修正を優先します。

「PawPalの修正を解除」で外部取得情報に戻せます。

## 検索範囲
現在地から50km以内。
