# PawPal v20.8 — 店舗情報の自動補完候補

## 追加
運営管理の店舗編集画面に「店舗情報の自動補完候補」を追加。

候補取得元:
- OpenStreetMap
- Overpass
- Nominatim
- Wikidata / Wikipedia（タグに含まれる場合）

候補対象:
- 住所
- 電話
- ホームページ
- 営業時間

## 安全設計
- 見つかった情報を自動保存しない
- 候補だけ表示
- 管理者がチェックしてフォームへ反映
- 最後に「Supabaseへ保存」を押して確定

## 使い方
1. 運営管理で店舗を「編集」
2. 「🔎 補完候補を探す」
3. 見つかった候補を確認
4. 反映したい項目だけチェック
5. 「✅ 選択した候補をフォームへ反映」
6. 内容を確認
7. 「☁️ Supabaseへ保存」
