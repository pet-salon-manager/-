# PawPal v18.2

## 重要修正
バーコード読み取り画面の × と「商品画面に戻る」が押せない問題を根本修正。

原因:
バーコードモーダルのHTMLが app.js より後にあり、
JavaScript実行時点で閉じるボタンがまだDOMに存在していませんでした。

修正:
- バーコードモーダルHTMLを先に読み込む
- app.js を body 最後で読み込む
- × ボタンを確実にイベント登録
- 「商品画面に戻る」ボタンを確実にイベント登録
- 背景タップ閉じる処理も維持
- 写真読み取り要素がなくてもJSが停止しないよう防御

v18のJAN/EANカメラ読み取り機能はそのままです。
