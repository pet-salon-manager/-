# PawPal v20.4 — Supabase店舗優先表示 修正版

## 修正
- 同じ店舗が「外部検索」と「Supabase店舗マスタ」の両方にある場合、
  Supabase版を優先して残すように修正。
- 運営管理一覧で `☁️ Supabase店舗` と分かるように表示。
- Supabase版の「編集」を開くと、
  `☁️ Supabaseへ保存` / 公開・非公開 / 削除 が利用できます。
- キャッシュを v20.4 に更新。

## 使い方
1. GitHubへv20.4のファイルを上書きアップロード
2. PawPalを再読み込み
3. お店画面で「店舗マスタを同期」
4. 「⚙️ PawPal運営管理」を開く
5. `☁️ Supabase店舗` と出ている店舗の「編集」を押す
