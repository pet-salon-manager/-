# PawPal Pet Super App v21.6

## v21.6 変更点
- 店舗編集画面に「🗑️ このお店を削除」を表示
- 削除ボタンのイベントを修正し、実際にSupabase店舗マスタから削除
- 削除前に確認ダイアログを表示
- 削除済み店舗の external_id を端末に記録し、OpenStreetMap / Overpassから再取得されても再表示・再登録を防止
- 一括店舗マスタ登録・都道府県取り込みでも削除済み店舗を除外

# PawPal v21.5.1 — 店舗マスタ検索

PawPal店舗マスタ一覧に専用検索を追加しました。

## 検索対象
- 店名
- 都道府県
- 市区町村
- 住所
- 種類
- 電話
- ホームページ

## 絞り込み
- 種類
- 都道府県

## 表示
- 最初は20件
- 検索結果も20件ずつ
- 「次の20件を見る」で追加表示
- 該当件数 / 店舗マスタ総件数を表示

検索結果からそのままPawPalおすすめON/OFFができます。
