# PawPal v19.2

## お店の複数条件フィルター
複数の条件を同時に選択できます。

例:
- 🏨 ホテル + ❤️ お気に入り
- 🏥 病院 + ⭐ おすすめ
- ✂️ トリミング + ❤️ お気に入り + ⭐ おすすめ
- 🛍️ ペットショップ + ⭐ おすすめ

### 判定方法
- 店舗種類（病院 / トリミング / ホテル / ペットショップ）を複数選んだ場合は「いずれか」に該当すれば対象
- ❤️お気に入りを追加すると、お気に入り登録済みだけに絞る
- ⭐おすすめを追加すると、おすすめ店舗だけに絞る
- ❤️お気に入り + ⭐おすすめを両方選ぶと、両方を満たす店舗だけを表示
- 「すべて」で選択条件を一括解除

50km検索、複数情報源、運営管理による店舗編集はv19.1から継承しています。
