# PawPal v21.1 — 全国47都道府県の実店舗取り込み

## 追加
静岡県限定だった実店舗取り込みを全国47都道府県対応にしました。

### 流れ
1. 都道府県を選択
2. 「選択した都道府県の店舗候補を取得」
3. 候補を確認
4. 保存する店舗をチェック
5. 「選択店舗をSupabaseへ保存」
6. 店舗マスタを同期

### 対象
- 動物病院
- ペットショップ
- トリミング
- ペットホテル系

### データ元
- OpenStreetMap
- Overpass

### 安全
- 保存にはPawPal運営管理者ログインが必要
- Supabase RLSで管理者UIDのみ書き込み可能
- 同じ external_id は upsert で更新
