# PawPal v20.9.1 — 店舗編集が開かない問題の修正

## 修正内容
運営管理画面はSupabaseの全店舗を表示していますが、
編集ボタン側が「現在地周辺のお店一覧」だけから店舗を探していたため、
一部の店舗では「編集」を押しても画面が開きませんでした。

v20.9.1では、
- 現在地周辺のお店一覧
- Supabase運営管理の全店舗一覧

の両方から店舗を探すように修正しました。

これにより、運営管理に表示されるSupabase店舗は
距離に関係なく編集画面を開けるようになります。

## 使い方
1. GitHubへv20.9.1を上書き
2. PawPalを再読み込み
3. 店舗マスタを同期
4. 運営管理を開く
5. これまで開かなかった店舗の「編集」を試す
