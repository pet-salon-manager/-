# PawPal v17

## 新機能：バーコードカメラ読み取り
商品画面の「📷 カメラで読み取る」からJANコードを読み取れます。

- iPhoneの背面カメラを優先
- EAN-13 / EAN-8 / UPC-A / UPC-E を認識
- 登録済みJANなら商品を即表示
- 未登録JANなら商品登録フォームへ自動入力
- カメラ権限エラー表示
- 読み取り成功時に自動でカメラを閉じる
- 手入力JAN検索も引き続き利用可能

## 注意
ブラウザが BarcodeDetector API に対応している必要があります。
非対応端末ではJAN手入力を案内します。

HTTPS環境（GitHub Pages）で利用してください。
