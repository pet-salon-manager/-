# PawPal ペットスーパーアプリ v1

iPhone Safari で使えるシンプルなWebアプリです。

## 主な機能
- ペット登録・切り替え
- 健康記録（体重・体調・メモ）
- 予定管理（薬・病院・トリミング・ワクチン等）
- お店検索（サンプルデータ）
- JANコード・商品名検索（サンプルデータ）
- iPhoneのlocalStorageに自動保存
- PWA用 manifest / service worker 同梱
